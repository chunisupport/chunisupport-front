# 画面上部エラー表示の調査

## 調査範囲

- 対象: `src/pages` 配下で、ページ見出し直下または主要コンテンツの先頭付近に `message()` / `errorMessage()` などを表示している実装。
- 除外: 入力欄・ボタン・ダイアログ内など、操作対象の近くに出ているエラー表示。
- 備考: `toUserFriendlyErrorMessage(...)` を通る文言は、APIエラーコードやHTTPステータスに応じて `src/types/api.ts` / `src/utils/errorMessage.ts` の共通文言に置き換わる。

## フレンド画面

上部エラー表示:

- `ユーザー名のコピーに失敗しました。`
- `操作に失敗しました。`
- `toUserFriendlyErrorMessage(pageData.error)` の共通文言

上部成功通知も同じ位置に表示される:

- `フレンド申請を送信しました。`
- `フレンド申請を取り消しました。`
- `フレンド申請を承認しました。`
- `フレンド申請を拒否しました。`
- `フレンドを解除しました。`

上部ではなく入力欄付近に出るため除外した文言:

- `ユーザーが見つかりません`
- `フレンド申請に失敗しました。`

## 楽曲管理の固定エラー文言

`/admin/songs` と `/editor/songs` は同じ `SongManagementPage` を利用している。

- `マスターデータの取得前のためULTIMA譜面を追加できません。`
- `ULTIMA難易度のマスターデータが見つかりません。`
- `マスターデータの取得前のため更新できません。再読み込みしてください。`
- `リリース日の形式が不正です。日付を入力し直してください。`
- `譜面の定数・ノーツは0以上で入力してください。`
- `マスターデータの取得前のため追加できません。再読み込みしてください。`
- `公式ID・タイトル・アーティストは必須です。`
- `公式IDは10文字以内で入力してください。`
- `ジャンルを選択してください。`
- `BPMは0以上で入力してください。`
- `追加する譜面の定数・ノーツは0以上で入力してください。`
- `WORLD'S ENDレベルは1〜5で入力してください。`
- `ノーツは0以上で入力してください。`
- `更新に失敗しました。`
- `追加に失敗しました。`
- `削除に失敗しました。`
- `復活に失敗しました。`

APIエラーコードやHTTPステータスが取れる場合、末尾4件の fallback 文言ではなく共通文言が表示される可能性がある。

## スコア登録（一時）の固定エラー文言

アップロード側:

- `ファイルサイズは5MB以下にしてください。`
- `アップロードできるのは .json または .txt のみです。`
- `アップロードするファイルを選択してください。`
- `JSONの形式が正しくありません。`
- `アップロードに失敗しました。`

確定保存側:

- `uploadToken を入力してください。`
- `アップロードトークンが見つかりません。`
- `保存に失敗しました。`

APIエラーコードやHTTPステータスが取れる場合、`アップロードに失敗しました。` / `保存に失敗しました。` ではなく共通文言が表示される可能性がある。

上部成功通知も同じ周辺に表示される:

- `スコアデータを送信しました。`
- `スコアデータを確定保存しました。`

## 共通エラー文言

`toUserFriendlyErrorMessage(...)` 経由で表示され得る主な共通文言:

- `リクエスト形式が不正です`
- `サーバーエラーが発生しました`
- `認証が必要です`
- `アクセス権限がありません`
- `ユーザーが見つかりません`
- `操作に失敗しました`
- `入力内容に誤りがあります`
- `データが見つかりません`
- `データが競合しています`
- `データサイズが大きすぎます`
- `フレンド枠の上限に達しています`
- `既に申請中、またはフレンドになっています`
- `対象のフレンド申請が見つかりません`
- `リソースが見つかりません`
- `リクエストが多すぎます。しばらく待ってから再試行してください`
- `サービスが一時的に利用できません`
- `予期せぬエラーが発生しました。時間をおいて再度お試しください。`

## 対象外として確認したもの

- ログイン画面・新規登録画面: フォームカード内の認証エラー表示であり、ページ全体上部の通知バナーではない。
- フレンド申請フォームの `requestErrorMessage`: ユーザー名入力欄のラベル付近に出るため、AGENTS.md の「対象要素の近くに表示」に近い。
- 称号編集ダイアログの `formErrorMessage`: ダイアログ内の保存フォーム近くに出るため、ページ上部エラーではない。
- レコードフィルター保存ダイアログ等のダイアログ内エラー: ダイアログ内の操作対象に紐づく表示のため除外。
