# 集計・境界値の扱い

## 楽曲一覧のジャンル順

通常楽曲とWORLD'S ENDの一覧では、ジャンルをマスタの表示順で並べます。マスタにないジャンルは昇順・降順とも末尾に置きます。

## OVER POWERの内訳

ジャンル・バージョンがない譜面も「不明」行に含めます。ジャンル・バージョン別の内訳を合計するとALLに一致します。グラフのスコア帯・コンボ帯も同じ分類を使い、未プレイ譜面をOTHERに含めます。

## ボーダー計算

候補一覧の目標JUSTICE数は下限値を表し、指定値そのものを含みます。候補は `justice >= targetJustice` を満たし、未指定時の下限は0です。

## 分位点

フィルター統計と苦手譜面インスペクターは、昇順の数列に対して線形補間で分位点を求めます。位置は `(件数 - 1) × 分位` とし、両隣の値を補間します。
