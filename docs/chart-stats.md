# レコード統計

`/tools/chart-stats` は、全プレイヤーを対象に集計した譜面別のレコード統計を表示する公開ページです。

## データ取得

フロントエンドのホスト名へ `static.` を付けた配信元から、難易度別のJSONを取得します。
`PUBLIC_CHART_STATS_BASE_URL` が設定されている場合は、その配信元を優先します。ローカル開発では `https://static.chunisup-dev.f5.si` を使用します。

| 難易度 | パス |
| --- | --- |
| BASIC | `/v1/chart-stats/BASIC.json` |
| ADVANCED | `/v1/chart-stats/ADVANCED.json` |
| EXPERT | `/v1/chart-stats/EXPERT.json` |
| MASTER | `/v1/chart-stats/MASTER.json` |
| ULTIMA | `/v1/chart-stats/ULTIMA.json` |
| WORLD'S END | `/v1/chart-stats/WORLDS_END.json` |

`rank`、`clear`、`combo` の各値は排他的な人数です。グラフは排他的な人数の構成比を表示し、表は既定で区分ごとの排他人数または達成率を表示します。`累積` を有効にすると各到達条件以上の累積人数または達成率を表示します。達成率の分母は `player_count` です。

## 表示仕様

- 初期難易度は `MASTER`、初期表示は `RANK` のグラフです。
- グラフ表示と表表示はどちらもTanStack Virtualで仮想化された1譜面1行の表形式で、ページングしません。
- グラフ表示は曲名、定数、人数、分布グラフを横並びにします。
- 定数と人数の列は中央揃えです。WORLD'S ENDでは定数の代わりに `Lv./属性` を表示します。
- グラフと表では `人数` と `割合` を切り替えられます。グラフの人数表示では最大プレイ人数を100%としてバー幅を伸縮させ、割合表示では全行を同じ幅にします。グラフには数値を表示しません。
- グラフの帯は行高を抑えた細い表示とし、曲名セル全体から楽曲詳細へ移動できます。
- 集計カテゴリは `RANK`、`COMBO`、`HARD` を切り替えられます。
- 表では達成率に応じたヒートマップを常時表示します。セル内の数値は常に残します。
- 曲名検索はUnicode正規化後の部分一致です。検索欄右のフィルターボタンからバージョン、ジャンル、楽曲名順で絞り込めます。楽曲名順は楽曲マスタの `name_folder_code` で判定し、全選択では絞り込みません。バージョンは楽曲のリリース日から解決したフルネームで判定し、マスタにない譜面は不明扱いとします。
- 表はすべての列、グラフは曲名・定数・人数の列と分布グラフの各凡例を操作してソートできます。人数表示では該当区分の人数、割合表示では `player_count` に対する割合を丸めずに比較します。グラフの凡例には排他的な値、表には表示中の累積または排他的な値を使います。分母が0で割合を算出できない譜面は末尾へ置きます。同じ項目を押すと少ない順、多い順、解除の順に切り替わります。ソート状態は画面内に閉じて保持し、集計カテゴリの切り替え時に解除します。表では累積表示の切り替え時にも解除します。
- 曲名から、選択中の難易度を指定した楽曲詳細へ移動できます。

## ダウンロード

最終更新日時の右にあるダウンロードボタンからダイアログを開き、難易度と形式（`JSON`、`CSV`、`TSV`）を選んで1ファイルとして保存します。

- 通常難易度（BASIC〜ULTIMA）は複数選択できます。WORLD'S ENDは列構成が異なるため単独でのみ選択でき、WORLD'S ENDを選ぶと通常難易度の選択が、通常難易度を選ぶとWORLD'S ENDの選択が外れます。
- ダイアログを開くと表示中の難易度だけが選択された状態になります。表示していない難易度はダウンロード時に取得し、取得済みの難易度はキャッシュを使います。
- `検索・フィルターを適用` が有効な場合、画面の曲名検索とフィルター条件を選択したすべての難易度に同じく適用します。WORLD'S ENDには定数範囲を適用しません。ジャンル・バージョン・楽曲名順の条件がある場合は、選択した難易度の楽曲マスタとバージョンを取得し終えるまでダウンロードできません。ダウンロード中はダイアログを閉じられません。
- 値は表示形式（グラフ／表、人数／割合、累積）に関係なく、静的JSONと同じ排他的な人数です。並び順は画面上のソートに関係なく、難易度タブの順・静的JSONの順です。
- `JSON` は `{ "stats": [静的JSON, ...] }` の形で、難易度ごとの静的JSONを `charts` だけ絞り込み後の譜面に置き換えて並べます。
- `CSV` と `TSV` は1譜面1行で選択した難易度を連結し、Excelで開けるようUTF-8 BOM付き、改行はCRLFです。列は `difficulty`、`song_id`、`title`、レベル情報（通常難易度は `const`・`is_const_unknown`、WORLD'S ENDは `level_star`・`attribute`）、`player_count`、`rank_*`、`clear_*`、`combo_*` の順で、各カテゴリは上位区分から並べます。
- ファイル名は `chart-stats_{難易度}_{生成日(JST, YYYYMMDD)}.{拡張子}` です。複数難易度は `-` でつなぎ（例: `BASIC-MASTER`）、通常難易度をすべて選んだ場合は `ALL` です。WORLD'S ENDは `WORLDS_END`、生成日は選択した難易度で最も新しい日付です。
