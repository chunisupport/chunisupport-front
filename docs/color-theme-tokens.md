# カラーテーマとデザイントークン

このドキュメントは、画面で使用する色を「背景テーマ」「アクセントカラー」「意味固定色」に分類する基準を定めます。基準実装は `src/styles/tailwind.css`、設定の適用処理は `src/utils/themePreference.ts` です。

## 目的

背景の明暗や色味と、操作を強調するブランドカラーを独立して変更できるようにします。一方、状態やゲーム内情報を伝える色はテーマ変更の影響を受けないようにし、同じ色が常に同じ意味を表す状態を維持します。

ルート要素では、次の2軸を別の属性として扱います。

```html
<html data-theme="black" data-accent="green">
```

- `data-theme`: 背景、サーフェス、文字、枠線など、画面の明暗と土台を決める。
- `data-accent`: プライマリ操作、選択状態、フォーカス、リンクなど、操作上の強調色を決める。

現在の背景テーマは `light`、`pastel-orange`、`dark`、`black`、アクセントカラーは `green`、`orange`、`blue` です。`pastel-orange` は低彩度の黄橙・橙・赤橙を背景とサーフェスに用いるライトテーマです。アクセントカラーの追加時も、背景テーマや意味固定色を複製しません。

## 分類基準

### 背景テーマ

「背景が変わると、読みやすさや要素の境界を維持するために調整が必要か」を基準に分類します。

対象は次のとおりです。

- ページ、カード、ダイアログ、ホバーなどのサーフェス
- 本文、補助文、プレースホルダー、ナビゲーションの文字色
- 通常・強調枠線
- セカンダリ操作
- 入力欄、無効状態、オーバーレイ
- ブラウザー標準UIへ伝える `color-scheme`

これらは `--cs-color-bg`、`--cs-color-surface-*`、`--cs-color-text-*`、`--cs-color-border-*` などのセマンティックトークンとして定義します。

### アクセントカラー

「色相を変えても機能上の意味が変わらず、操作対象や現在の選択を強調する色か」を基準に分類します。

対象は次のとおりです。

- プライマリボタンとホバー状態
- 選択中・アクティブ状態
- フォーカスリング
- リンク
- チェックボックスなどの選択済み状態
- 薄いアクセント背景とアクセント枠線

色相パレットは `--cs-color-accent-50` から `--cs-color-accent-900` に定義し、既存コードとの接続点である `--color-primary-*` を経由して利用します。ライト背景とダーク背景では必要なコントラストが異なるため、実際に使う段階は背景テーマ側の `--cs-color-action-primary` などで選びます。

### 意味固定色

「その色自体が状態やドメイン情報を伝えているか」を基準に分類します。意味固定色は背景テーマにもアクセントカラーにも連動させません。

対象は次のとおりです。

- 危険、削除、リセット、エラー
- 成功、警告、情報
- 難易度
- スコアランク
- クリア・コンボランプ
- ランキングメダル
- WORLD'S END
- グラフ系列など、色と凡例の対応が固定されているもの

背景とのコントラスト確保のために明度や背景透過率をテーマ別に調整することは許可します。ただし、赤を危険、黄を警告として扱うなどの意味と色相の対応は変更しません。

## 判断手順

新しい色を追加するときは、次の順に判断します。

1. 状態やドメイン値を識別する色なら、意味固定色にする。
2. 操作対象、選択状態、フォーカスを強調する色なら、アクセントカラーから派生させる。
3. 背景、文字、境界、入力欄など、周囲とのコントラストを作る色なら、背景テーマへ追加する。
4. どれにも該当しない装飾色は、既存トークンで表現できない理由を確認してから用途固有トークンとして追加する。

コンポーネント内へ色値を直接記述せず、意味が分かるセマンティックトークンを使用します。

## アクセントカラー追加時の要件

新しいアクセントカラーを追加する場合は、次をすべて満たす必要があります。

- `data-accent` の値と `--cs-color-accent-50` から `900` のパレットを追加する。
- ライト、ダーク、ブラックの各背景で、通常文字は4.5:1以上、UI境界とフォーカス表示は3:1以上のコントラストを確認する。
- プライマリ操作、ホバー、薄い背景、枠線、リンク、フォーカスを確認する。
- 危険、成功、警告、難易度、ランクなどの意味固定色が変化しないことを確認する。
- 設定をユーザーへ公開する場合は、保存値の読み取り、適用、単体テストを追加する。
