# フレンドVS

`/tools/friend-vs` では、ログインユーザーと承認済みフレンド1人の通常譜面スコアを比較する。フレンド画面の各カードにある「フレンドVS」から開くと相手を選択した状態になる。ツール一覧から開いた場合は相手を選択する。

難易度は `BASIC`、`ADVANCED`、`EXPERT`、`MASTER`、`ULTIMA` から1つ選び、初期値は `MASTER` とする。フレンドと難易度が選択されたとき、Firebase認証付きの `GET /internal/friend-comparisons/:username/charts/:difficulty` を呼び出す。

集計には未プレイを含む全有効譜面を使用する。スコア差は自分のスコアから相手のスコアを引いた値で、同点はランプやプレイ状態にかかわらず引き分けとなる。未プレイはスコア0として比較するが、一覧では「未プレイ」と表示してプレイ済みのスコア0と区別する。

対戦結果は双方の勝ち数と引き分け数を並べて表示する。挑戦状況は「ふたりとも」「あなたのみ」「相手のみ」「どちらもまだ」の4区分を帯と凡例で示す。

「対戦譜面」の一覧は勝敗またはふたりとも挑戦した譜面で絞り込める。曲名、譜面定数、自分のスコア、フレンドのスコア、スコア差の列見出しから、昇順・降順・解除を切り替える。解除時はAPIの楽曲順に戻る。曲名から対象楽曲の同じ難易度へ移動できる。フレンド解除、ログアウト、スコア更新時には比較データのキャッシュを更新または破棄する。
