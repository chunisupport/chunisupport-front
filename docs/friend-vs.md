# フレンドVS

`/tools/friend-vs` では、ログインユーザーと承認済みフレンド1人の通常譜面またはWORLD'S END譜面のスコアを比較する。ツール一覧から開いた場合は相手を選択する。

「難易度」プルダウンで `BASIC`、`ADVANCED`、`EXPERT`、`MASTER`、`ULTIMA`、`WORLD'S END` から1つ選ぶ。初期値は `MASTER` とする。通常難易度ではFirebase認証付きの `GET /internal/friend-comparisons/:username/charts/:difficulty`、WORLD'S ENDでは `GET /internal/friend-comparisons/:username/worldsend` を呼び出す。難易度ごとの比較結果は別々にキャッシュする。

APIの比較には未プレイを含む全有効譜面を使用する。スコア差は自分のスコアから相手のスコアを引いた値で、同点はランプやプレイ状態にかかわらず引き分けとなる。未プレイはスコア0として比較するが、一覧ではダッシュを表示し、読み上げとツールチップでは「未プレイ」と伝える。

「対戦結果」には双方が挑戦した譜面だけの勝敗を、自分視点の `WIN`・`DRAW`・`LOSE` で表示する。

「スコア比較」はカード表示と表表示を切り替えられ、初期値はカード表示とする。どちらも仮想スクロールを使い、楽曲名、通常譜面の譜面定数またはWORLD'S ENDの星数・属性、自分とフレンドのスコア、スコア差を表示する。WORLD'S ENDの星数・属性が未設定の場合は星数を `★-` で表示する。カードにはアーティストと、双方が挑戦した譜面の自分視点の `WIN`・`DRAW`・`LOSE` も表示する。勝っている側のスコアだけをアクセントカラーの太字にする。勝敗による絞り込みは両表示で共通とし、勝敗フィルターは双方が挑戦した譜面だけを対象にする。並び替え状態も両表示で共有し、カード表示では項目と昇順・降順を選び、表表示では列見出しを操作する。標準順ではAPIの楽曲順に戻る。曲名から通常譜面は対象楽曲の同じ難易度、WORLD'S ENDは対象のWORLD'S END楽曲詳細へ移動できる。フレンド解除、ログアウト、スコア更新時には比較データのキャッシュを更新または破棄する。
