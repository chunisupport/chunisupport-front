# フレンドVS

`/tools/friend-vs` では、ログインユーザーと承認済みフレンド1人の通常譜面スコアを比較する。フレンド画面の各カードにある「フレンドVS」から開くと相手を選択した状態になる。ツール一覧から開いた場合は相手を選択する。

難易度は `BASIC`、`ADVANCED`、`EXPERT`、`MASTER`、`ULTIMA` から1つ選び、初期値は `MASTER` とする。フレンドと難易度が選択されたとき、Firebase認証付きの `GET /internal/friend-comparisons/:username/charts/:difficulty` を呼び出す。

APIの比較には未プレイを含む全有効譜面を使用する。スコア差は自分のスコアから相手のスコアを引いた値で、同点はランプやプレイ状態にかかわらず引き分けとなる。未プレイはスコア0として比較するが、一覧ではダッシュを表示し、読み上げとツールチップでは「未プレイ」と伝える。

「対戦結果」には双方が挑戦した譜面だけの勝敗を、自分視点の `WIN`・`DRAW`・`LOSE` で表示する。「挑戦状況」は全譜面を「ふたりとも挑戦」「自分のみ挑戦」「フレンドのみ挑戦」「どちらも未挑戦」の4区分に分け、アクセントカラーとは独立した色の帯と凡例で示す。

「スコア比較」の一覧は `WIN`・`DRAW`・`LOSE` または双方が挑戦した譜面で絞り込める。勝敗フィルターは双方が挑戦した譜面だけを対象にする。勝っている側のスコアだけをアクセントカラーの太字で表示する。楽曲、定数、自分、フレンド、スコア差の列見出しから、昇順・降順・解除を切り替える。解除時はAPIの楽曲順に戻る。曲名から対象楽曲の同じ難易度へ移動できる。フレンド解除、ログアウト、スコア更新時には比較データのキャッシュを更新または破棄する。
