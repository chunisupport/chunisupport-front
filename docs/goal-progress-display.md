# 目標の進捗表示

目標カードは、進捗対象が1件以上ある場合に現在値、目標値、進捗ゲージを表示します。進捗対象が0件の場合は数値とゲージを表示せず、「対象譜面なし」と表示します。虹枠目標では対象単位が楽曲のため、対象曲がない場合も同じ表示文言を使います。この状態は未達成として扱います。

進捗対象数は目標種別に応じて決まります。

- 通常の譜面目標は、条件で絞り込まれた譜面数です。
- 単曲レート達成数は、設定した単曲レートへ到達可能な譜面数です。
- 虹枠目標は、条件に一致し必要な難易度が揃った楽曲数です。
- OVER POWER目標は、集計条件で選ばれた譜面数です。未解禁曲設定の対象となる譜面は集計対象から除きます。

平均スコア目標では、現在平均、目標平均、進捗ゲージを表示します。割合の表示位置には「あと〇〇点」を表示し、譜面のスコア合計が目標平均へ届くまでの必要点数を示します。

必要点数は、対象譜面の現在スコア合計と対象譜面数から次の式で計算します。

`max(0, ceil(目標平均 × 対象譜面数 − 現在スコア合計))`

平均スコア目標では、数値表示と割合表示の反転設定を適用しません。進捗ゲージは達成率を示し続けます。必要点数が0点の場合も「あと0点」と表示します。

目標の作成・更新時は、対象が0件の条件を保存できません。保存後に楽曲やプレイヤーデータの変化で対象が0件になった場合は、カードで「対象譜面なし」と表示します。
