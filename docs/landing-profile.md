# トップページのプロフィールカード

ログイン済みのトップページでは、マイページと共通の名札を表示します。
称号、レベル、プレイヤー名、公開ユーザー名、計算済みRATING（BEST・NEW平均）、OVER POWER・達成率を表示し、マイページへの導線を設けます。履歴ボタンは表示しません。
公開ユーザー名は左揃えで表示し、称号はカード内の横幅いっぱいに表示します。
背景色はポゼッションに応じて変わります。称号が複数ある場合は自動切り替えと縦並び表示を利用できます。

プロフィールの `player` が `null` の場合は、公開ユーザー名と未登録表示、データ登録方法とマイページへの導線を表示します。数値欄は表示せず、レーティングAPIも呼び出しません。
取得中は共通のLoading、取得失敗時はカード内のエラー表示と再試行ボタンを表示します。

レーティング取得は本人用の既存キャッシュを利用します。通常譜面の全レコードはトップページでは取得しないため、OVER POWERの定数未判明判定はマイページで確認できます。
