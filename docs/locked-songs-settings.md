# 未解禁楽曲設定

OVER POWER画面の未解禁楽曲設定ダイアログで、計算から除外する通常楽曲とULTIMA譜面を選択します。

検索ツールバー右端のロックアイコンは「要解禁楽曲のみ表示」を切り替えます。初期状態はオンで、内部楽曲API (`GET /internal/songs`) の `unlock_required` が `true` の楽曲だけを表示します。ULTIMA行も所属する楽曲の同じフラグで絞り込みます。オフにすると、要解禁フラグにかかわらず楽曲を表示します。

検索、ジャンル、バージョン、プレイ状況、選択済み楽曲のみ表示は、要解禁楽曲の絞り込みと同時に適用されます。「要解禁楽曲のみ表示」はフィルターダイアログのリセット対象には含まれません。ダイアログを閉じて再度開いた場合も、画面内では切り替え状態を保持します。

表示の絞り込みによって選択中の未解禁設定は解除されません。保存時は非表示の選択も含めて反映されます。
