# OVER POWER計算機

`/tools/overpower-calc` は未ログインでも数値と達成率の相互計算、獲得値への加算、97.5%・99.0%・99.5%のボーダー表を利用できます。

ログイン時は自身の通常レコードと未解禁設定から獲得値・満点・目標達成率を自動入力します。集計には OVER POWER画面と同じ `buildOverPowerChartEntries` / `selectOverPowerChartEntries` を使用します。未解禁設定の編集は既存の未解禁楽曲設定ダイアログで行い、保存後に再取得します。「未解禁設定曲を解禁扱いにする」は計算時のみ設定の除外を無効にします。

目標達成率とボーダー表の差分は、ログイン時はインポートした獲得値を基準にします。手入力・加算した獲得値は「数値→%」に反映されます。未ログイン時は差分にも手入力した獲得値を使います。

未プレイ除外計算はログイン時に利用できます。未プレイ判定は利用可能な理論値対象譜面を基準とし、下位譜面をプレイ済みでも理論値対象が未プレイなら補完対象です。ULTIMAを未解禁に指定した場合は利用可能な最大定数の譜面を使います。

補完方法は現在値の維持、曲の除外、理論値、既プレイ平均、定数別の既プレイ平均、定数別平均の線形回帰、指定スコアの7種類です。平均は現在OP対象の既プレイ譜面から求めます。定数別平均のサンプルがない定数は0点、線形回帰は定数別平均を各1点として推定し、予測を0〜1,010,000点に制限します。

スコア補完は旧版のシミュレーション仕様を維持します。975,000点未満は0、コンボ補正は加算せず、理論スコアの指定と「理論値で埋める」は区別します。補完によって既存の獲得値を下げず、楽曲の満点を上限とします。「存在を消す」は対象曲の獲得値と満点を両方除外します。
