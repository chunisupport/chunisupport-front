# OVER POWER計算機

`/tools/overpower-calc` は未ログインでも数値と達成率の相互計算、獲得値への加算、目標達成までの必要譜面数の表を利用できます。

ログイン時は自身の通常レコードと未解禁設定から獲得値・OVER POWER理論値・目標達成率を自動入力します。集計には OVER POWER画面と同じ `buildOverPowerChartEntries` / `selectOverPowerChartEntries` を使用します。未解禁設定の編集は既存の未解禁楽曲設定ダイアログで行い、保存後に再取得します。「未解禁曲を計算から除外する」は初期状態でチェック済みです。チェックを外すと、計算時のみ未解禁曲を含めます。

自動入力はユーザーごとの初回集計で行います。同じユーザーの再取得では、編集済みのOVER POWER理論値・獲得値と目標達成率を保持し、未編集のOVER POWER理論値・獲得値のみ最新の集計値へ更新します。初回読み込み中に編集した入力も保持します。未解禁設定の保存・未解禁曲の除外切り替えで集計対象が変わった場合は、OVER POWER理論値・獲得値に集計値の増減を反映し、手入力・加算による調整分と目標達成率を保持します。ユーザー変更・ログアウトでは入力と編集状態を初期化します。

目標達成率の差分は、ログイン時はインポートした獲得値を基準にします。手入力・加算した獲得値は「数値→%」に反映されます。未ログイン時は差分にも手入力した獲得値を使います。

未プレイ補完計算はログイン時に利用できます。未プレイ判定は利用可能な理論値対象譜面を基準とし、下位譜面をプレイ済みでも理論値対象が未プレイなら補完対象です。ULTIMAを未解禁に指定した場合は利用可能な最大定数の譜面を使います。

補完方法は現在値の維持、曲の除外、理論値、既プレイ平均、定数別の既プレイ平均、指定スコアの6種類です。平均は現在OP対象の既プレイ譜面から求めます。定数別の既プレイ平均ではサンプルがある定数の平均をそのまま使い、サンプルがない定数だけ直近の両側の平均から補間します。範囲外は近い2定数の平均から外挿します（例: 16.0は15.8と15.9）。サンプルが1定数だけならその平均、全定数でサンプルがなければ0点とし、推定スコアは0〜1,010,000点に制限します。

スコア補完は旧版のシミュレーション仕様を維持します。975,000点未満は0、コンボ補正は加算せず、理論スコアの指定と「理論値」は区別します。補完によって既存の獲得値を下げず、楽曲のOVER POWER理論値を上限とします。「ないものとして扱う」は対象曲の獲得値とOVER POWER理論値を両方除外します。

画面は「数値→%」「%→数値」「未プレイ補完計算」の下線タブで切り替えます。入力と表示はOVER POWERを小数点以下3桁、達成率を5桁、譜面定数を1桁に固定します。加算入力は空欄から自由な小数表記で入力します。目標達成率の入力は0〜100%に制限し、97.5%・99.0%・99.5%のクイック入力を用意します。

入力欄の最大幅は桁数に合わせ、OVER POWERは9rem、譜面定数は5rem、必要譜面数のスコアは7remとします。狭い画面では親の幅に合わせて縮みます。加算欄全体の幅はOVER POWER／理論値の行に揃えます。目標達成率・未プレイ補完の指定スコアは従来の幅を維持します。

「%→数値」の計算結果は他のタブと同じ大きさの独立した数値表示とし、その直下に不足値を「あと 1234.567」の形式で緑色の太字で上詰め表示します。OVER POWER理論値の入力欄は結果の右下に配置し、最大幅8remのコンパクト表示として左にスラッシュを置きます。達成済みの場合は「あと 0.000」です。目標入力とクイック入力は、幅が足りる場合は横並び、足りない場合はボタンを右揃えで折り返します。

必要譜面数の現在スコアと目標スコアの入力欄の間には、右矢印のアイコンを表示します。

必要譜面数は譜面定数・現在スコア・目標スコアを入力し、1譜面あたりの増加OPで目標までの不足OPを割って切り上げます。現在スコアは通常ランプとして計算し、目標スコアの通常・FC・AJの3条件を「ランプ」「必要譜面数」の2列で表示します。初期値は定数15.0、現在スコア1,005,000、目標スコア1,007,500です。スコア・コンボ補正は既存の `calculateSingleOverPower` を使用します。理論値は通常列のみ表示し、FC・AJは「—」です。増加OPが0以下なら「—」、目標達成済みなら有効な条件は0譜面です。実際の更新可能な譜面数の上限は考慮しません。

加算欄の下には、リザルト画面のOP増加値を随時加算して達成率を追えることと、毎回のレコード取得が不要であることを表示します。目標入力のラベルは「目標OP%」です。必要譜面数の説明は表の上に表示し、ランプは「なし」「FULL COMBO」「ALL JUSTICE」で表記します。

未プレイ補完の現在値維持は「何もしない」と表示します。「全曲既プレイ平均」の点数は小さく表示し、整数に丸めて3桁区切りのカンマを付け、単位は付けません。指定スコア入力は選択時にラジオカード内に表示し、必要譜面数のスコア入力と共通の `ScoreField` / `normalizeScoreRangeInput` で0〜1,010,000の整数に制限します。

未ログイン時の自動インポート案内は「数値→%」「%→数値」のタブ直下に表示します。「未プレイ補完計算」ではこの案内を表示せず、ログインが必要な旨を表示します。

「定数ごとの既プレイ平均」には小さな「※」を付け、未プレイ補完計算の選択肢の下に小さな注記で補間・端の推定方法を説明します。
