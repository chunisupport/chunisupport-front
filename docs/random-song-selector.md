# ランダム選曲の目標絞り込み

「目標で絞る」から保存済み目標を選択して「適用」すると、対象条件に一致する未達成譜面から均等に選曲します。キャンセルでは選択を変更しません。

- 対応する目標: ランク、スコア、平均スコア、単曲レート、ハードランプ、コンボランプ、FULL CHAIN、虹枠。
- 総スコア・OVER POWER の集計目標は選択対象外です。
- 目標適用中は、通常の難易度・ジャンル・バージョン・譜面定数・お気に入り・レコード絞り込み・重み設定を無効にします。曲数とレコード表示は変更できます。
- 「絞り込みなし」を適用すると元の通常設定に戻ります。条件リセットでは目標選択も解除します。
- 未プレイやレコードのない譜面は、スコア・単曲レートを0、ランプを未取得として扱います。
- 単曲レート目標では理論値でも到達できない譜面と定数不明の譜面を除外します。
- FULL CHAIN は目標に指定した色との一致で判定します。
- 虹枠目標はジャンル・バージョン条件に一致し、BASIC〜MASTER が揃った楽曲が対象です。ULTIMA を含め、存在する通常譜面の未AJ譜面を候補とします。
- 平均スコア目標は指定平均スコア未満の譜面を候補にします。目標の件数・割合や反転表示設定は、譜面単位の未達成判定を変更しません。

目標やレコードを取得できない場合は、選択ダイアログ内に理由を表示します。ログインしていない場合も通常のランダム選曲は利用できます。

実装は `src/utils/randomSongGoalFilter.ts` の純粋関数と、`src/pages/tools/RandomSongGoalDialog.tsx` の選択UIに分離しています。目標属性・ランプ・バージョン・単曲レート・虹枠の共通判定は `src/utils` に配置しています。
