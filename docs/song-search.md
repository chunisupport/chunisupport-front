# 楽曲DBの検索

通常曲とWORLD'S ENDの楽曲一覧は、文字列検索と属性フィルタを組み合わせて絞り込めます。

- BPMは上下限を含む範囲で指定します。小数と片側だけの指定に対応します。
- 追加日はゲームへの楽曲追加日です。開始日・終了日を含み、片側だけでも指定できます。
- ジャンルとバージョンは複数選択できます。同じ項目内はOR、異なる項目間と文字列検索はANDで適用します。
- バージョンは楽曲の追加日と各バージョンの稼働日から判定します。
- BPM・追加日の空欄は絞り込みません。ジャンル・バージョンは初期状態とリセット後に全選択で表示し、全選択では絞り込みません。「すべて解除」で選択を空にすると該当結果は0件になります。不明値はその項目の条件を指定した場合だけ除外します。
- 上下限が逆転している場合は入力欄付近にエラーを表示し、適用できません。
- 検索欄横のフィルターボタンからダイアログを開き、「適用」で条件を確定します。キャンセル、Esc、背景のクリックでは編集を破棄します。適用中はボタンを強調表示します。リセットアイコンはレコードと共通の確認ダイアログを表示します。確認後は編集中の属性条件のみを初期状態へ戻し、「適用」で反映します。検索文字列と並び順は保持します。
- フィルタは各一覧画面内で保持し、画面を離れると初期状態に戻ります。
ジャンル・バージョンを上部、BPM・追加日を下部に配置します。

## 通常曲の難易度列

フィルタ右側の切り替えボタンで、難易度列の主表示を譜面定数とノーツ数の間で切り替えられます。初期表示は譜面定数です。
各難易度セルは上段に主表示（大きく太い文字）、下段にもう一方の値（小さく細い文字）を同時に表示します。
難易度列の見出しを押すと、上段の値を基準に昇順・降順・解除の順でソートします。表示を切り替えてもソート対象列と方向は維持されます。
ノーツ数が未設定の場合は「-」と表示し、昇順・降順とも末尾に配置されます。譜面定数が未確定の場合は上段・下段どちらでも「?」を付けます。上段の値が未確定または未設定のときはセル全体を半透明にします。
