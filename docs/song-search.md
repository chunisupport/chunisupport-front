# 楽曲DBの検索

通常曲とWORLD'S ENDの楽曲一覧は、文字列検索と属性フィルタを組み合わせて絞り込めます。

文字列検索は、曲名・アーティスト名・読みをそれぞれ正規化して部分一致で比較します。お気に入り楽曲設定も同じ検索処理を使います。楽曲IDは検索対象に含めず、曲名とアーティスト名の境界をまたぐ一致も対象にしません。

- BPMは上下限を含む範囲で指定します。小数と片側だけの指定に対応します。
- 追加日はゲームへの楽曲追加日です。開始日・終了日を含み、片側だけでも指定できます。
- ジャンル、バージョン、楽曲名順は複数選択できます。同じ項目内はOR、異なる項目間と文字列検索はANDで適用します。
- バージョンは楽曲の追加日と各バージョンの稼働日から判定します。
- BPM・追加日の空欄は絞り込みません。ジャンル・バージョン・楽曲名順は初期状態とリセット後に全選択で表示し、全選択では絞り込みません。「すべて解除」で選択を空にすると該当結果は0件になります。不明値はその項目の条件を指定した場合だけ除外します。
- 上下限が逆転している場合は入力欄付近にエラーを表示し、適用できません。
- 検索欄横のフィルターボタンからダイアログを開き、「適用」で条件を確定します。キャンセル、Esc、背景のクリックでは編集を破棄します。適用中はボタンを強調表示します。リセットアイコンはレコードと共通の確認ダイアログを表示します。確認後は編集中の属性条件のみを初期状態へ戻し、「適用」で反映します。フィルターボタンを長押しし、進捗リングが完了してから指を離した場合は、適用済みの属性条件を直接リセットします。検索文字列と並び順は保持します。
- フィルタは各一覧画面内で保持し、画面を離れると初期状態に戻ります。
ジャンル・バージョン・楽曲名順を上部、BPM・追加日を下部に配置します。楽曲名順は楽曲マスタの `name_folder_code` で判定します。

## カード型一覧

通常曲とWORLD'S ENDの楽曲一覧はカード表示を初期表示とします。画面右上のアイコンボタンでカード表示と表表示を切り替えます。表示形式は通常曲とWORLD'S ENDの切り替え後も引き継ぎ、再読み込みするとカード表示へ戻ります。

通常曲とWORLD'S ENDのカード表示では、要解禁楽曲のカード右上に南京錠アイコンを表示します。

通常曲のカード表示では、並び順を画面上の Select で指定し、難易度は譜面定数とノーツ数を別キーとして選べます。カード全体のクリックで楽曲詳細へ遷移し、難易度未指定のため詳細側は MASTER を初期選択します。

WORLD'S ENDのカード表示では、並び順に属性・レベル・ノーツ数を選べます。カード下部は上段に属性と星（例: 狂 ★★★★★）、下段にノーツ数を表示します。カード全体のクリックで WORLD'S END 楽曲詳細へ遷移します。

## 楽曲管理画面

ADMIN向けの楽曲管理画面では、通常曲とWORLD'S END曲の各検索欄からジャンル・バージョン・楽曲名順・追加日で絞り込めます。文字列検索と各フィルター条件はANDで適用します。

欠落項目は追加日・BPM・ノーツ数・NOTES DESIGNER・Wikiページタイトルから選択し、「欠落のみ表示」を有効にすると、選択項目が未設定の楽曲だけを表示します。初期選択は追加日です。通常曲のノーツ数はBASIC〜MASTERと、存在するULTIMAを対象にします。NOTES DESIGNERはEXPERT・MASTERと、存在するULTIMAを対象にします。WORLD'S END曲はWORLD'S END譜面を対象にします。収録状態は収録中・削除済みから選択し、「楽曲のみ表示」を有効にすると、選択した状態の楽曲だけを表示します。初期選択は収録中です。フィルターボタンの長押し操作はレコード画面と共通で、進捗リングが完了してから指を離すと適用済み条件をリセットします。

楽曲管理の追加・編集フォームと楽曲情報編集ダイアログのWikiページタイトル欄では、生成ボタン（↲）で曲名を入力できます。曲名の `"`、`#`、`&`、`<`、`>`、`[`、`]`、`:` だけを全角に置き換え、その他の文字は維持します。外部リンクボタンは保存前の入力値に対応するWikiページを新しいタブで開きます。Wikiページタイトルが空白、またはWikiのベースURLが未設定の場合は外部リンクボタンが無効になります。

## 通常曲の難易度列

フィルタ右側の切り替えボタンで、難易度列の主表示を譜面定数とノーツ数の間で切り替えられます。初期表示は譜面定数です。
各難易度セルは上段に主表示（大きく太い文字）、下段にもう一方の値（小さく細い文字）を同時に表示します。
難易度列の見出しを押すと、上段の値を基準に昇順・降順・解除の順でソートします。表示を切り替えてもソート対象列と方向は維持されます。
ノーツ数が未設定の場合は「-」と表示し、昇順・降順とも末尾に配置されます。譜面定数が未確定の場合は上段・下段どちらでも「?」を付けます。上段の値が未確定または未設定のときはセル全体を半透明にします。

## 楽曲詳細の操作

EDITOR・ADMINは楽曲情報編集ダイアログで、通常曲とWORLD'S END曲の要解禁フラグを変更できます。ジャンルとBPMを1行目、リリース日と要解禁チェックボックスを2行目の2列に配置し、その下にWikiページタイトルを表示します。この要解禁フラグは楽曲マスタの属性であり、ユーザーごとの未解禁設定とは別に保存します。要解禁フラグがtrueの楽曲では、RELEASEの日付の直後に南京錠アイコンを表示します。

外部リンクは「Wiki」「YouTube」と表示します。通常曲ではYouTubeの横に正方形のお気に入りボタンを配置し、未登録は輪郭の星、登録中はアクセントカラーで塗りつぶした星を表示します。ログイン中はボタンから登録・解除でき、未ログイン時と取得・保存中は操作できません。取得・保存のエラーはボタン付近に表示します。WORLD'S ENDはお気に入り登録の対象外です。

お気に入りボタンの右には楽曲全体の未解禁設定ボタンを配置し、ULTIMA譜面がある曲ではさらに右に「ULT」ラベル付きの専用ボタンを表示します。未解禁設定なしは開いた南京錠、設定ありはアクセントカラーのボタンと閉じた南京錠で表示します。楽曲全体とULTIMA専用の設定は別々に保存し、楽曲全体の未解禁設定はULTIMAを含む全譜面に適用されます。ULTボタンはULTIMA専用設定の有無を表示します。「ULT」は小さなOswaldの文字でボタン内の右上に配置し、南京錠に少し重ねます。文字の背面はボタンと同じ背景色に揃え、重なった部分の南京錠を隠します。未ログイン時と取得・保存中は操作できず、エラーはボタン付近に表示します。
