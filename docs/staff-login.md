# メール・パスワードログイン

- URL は `/staff/login`。サイト内のメニュー・通常ログイン画面からの導線は設けない。
- 「スタッフ向けログイン画面です。ここからのログインはできません」を表示し、通常の `/login` へ案内する。
- Firebase Authentication のメール／パスワード認証を使い、Turnstile と既存の `/internal/auth/login` でログインを検証する。
- ロールによる制限は設けない。Firebase UID に紐づくユーザーが ChuniSupport の DB に存在する必要がある。
- Firebase 側でメール／パスワード認証を有効にし、管理者が対象アカウントを事前登録する。
- 新規登録・パスワード再設定の導線は設けず、ログイン失敗時はフォーム内にエラーを表示する。
- メンテナンス中も画面を表示するが、ログインの可否は既存 API のメンテナンス制限に従う。
- ログイン済みユーザーとログイン成功後の遷移は通常のログイン画面と同じ。`redirect` は既存の安全な遷移先検証を適用する。
- 検索エンジン向けに `noindex` を指定する。
- 再認証が必要な設定操作は Google 認証を使う既存仕様のため、メール／パスワード専用アカウントでは利用できない場合がある。
