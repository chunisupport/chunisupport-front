# ツールの利用条件

ツールは、自分のプレイヤーデータをどの程度使うかで、未ログイン時・プレイヤーデータ未登録時の挙動を分けます。

ログイン状態とプレイヤーデータ登録状態は `src/hooks/createPlayerDataStatus.ts` で判定します。認証セッションを解決したうえで `GET /internal/users/:username/profile` の `player` が `null` なら未登録として扱います。判定ロジックは `src/usecases/auth/resolvePlayerDataStatus.ts` の純粋関数です。

## 自分のプレイヤーデータが必須のツール

route に `RequirePlayerData`（`src/components/guards/RequirePlayerData.tsx`）を適用し、ページ本体を表示しません。

- 未ログイン: ログイン・新規登録を案内する（`LoginRequiredState`）。ログインリンクは現在のページへの復帰先を付与する
- プレイヤーデータ未登録: データ登録方法を案内する（`PlayerDataEmptyState`）

対象:

- ダッシュボード
- フレンドVS
- 苦手譜面インスペクター（Online・Unified を含む。Unified は ADMIN 権限も必要）
- 全曲ベスト枠
- ウニ埋めマトリックス
- 未解禁曲ディスカバー

## 一部機能だけが自分のプレイヤーデータを使うツール

ページは誰でも利用できます。未ログイン・未登録の場合は自分のデータを使う表示・操作だけを隠すか無効化し、ページ上部に `OwnDataNotice` でログインまたはデータ登録を案内します。

| ツール | 未ログイン・未登録時に使えないもの |
| --- | --- |
| ベスト枠・新曲枠理論値チェッカー | 自分のレーティングとの差、譜面ごとの自分のスコア |
| ベスト枠ランキング | 自分との差の列、自分のベスト枠のハイライト。初期レート帯は最高帯 |
| ランダム選曲 | お気に入りからランダム、自分のレコードで絞る、目標で絞る、レコードを表示 |
