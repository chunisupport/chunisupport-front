# 苦手譜面インスペクター Online

`/tools/weak-chart-inspector-online` は、ログインユーザーのプレイ済み通常譜面のスコアを、選択したベスト枠平均レート帯に属するプレイヤーの譜面別平均スコアと比較するページです。

## データ

レート帯はレート帯マスタの区間とログインユーザーの `best_average` から初期選択します。画面上で比較レート帯と難易度を変更できます。初期難易度は `MASTER` と `ULTIMA` です。

難易度別の平均スコアは静的配信元の `/v1/chart-scores/{DIFFICULTY}.json` から取得します。`PUBLIC_CHART_SCORES_BASE_URL` が設定されている場合はその配信元を使用し、未設定時はフロントエンドのホスト名へ `static.` を付けます。ローカル開発では `https://static.chunisup-dev.f5.si` を指定します。レコード統計の配信元は別の `PUBLIC_CHART_STATS_BASE_URL` で設定します。

静的統計の平均はクリア済み記録から算出されます。比較対象は自分のプレイ済み記録で、選択レート帯の平均が `null` の譜面と未プレイ譜面は表示しません。

## 表示

差分は `自分のスコア − 平均スコアの整数部分` です。散布図では横軸に譜面定数、縦軸に差分を表示します。平均より低い譜面と平均以上の譜面を色分けし、詳細はツールチップと表で確認できます。表は差分が低い譜面から並び、一度に100件ずつ表示します。
