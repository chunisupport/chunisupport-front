# 苦手譜面インスペクター Online

`/tools/weak-chart-inspector-online` は、ログインユーザーのプレイ済み通常譜面のスコアを、選択したベスト枠平均レート帯に属するプレイヤーの譜面別平均スコアと比較するページです。ログインが必要な公開ツールとして、管理者以外のユーザーにもツール一覧から表示します。

## データ

レート帯はレート帯マスタの区間とログインユーザーの `best_average` から初期選択します。画面上で比較レート帯を変更できます。右上の設定から、難易度、ジャンル、バージョン、表示スコア範囲、譜面定数をグラフと表に共通して適用できます。初期難易度は `MASTER` と `ULTIMA`、表示スコア範囲は ±10,000、譜面定数は 1.0～16.0 です。難易度には通常譜面に加えて `OP対象（MAS+ULT）` があり、通常難易度と同時選択できません。`OP対象（MAS+ULT）` は楽曲マスタの理論値OVER POWER対象譜面だけを表示し、平均スコアは `MASTER` と `ULTIMA` から取得します。平均スコアの取得と比較は、選択した難易度の全範囲を対象に行い、表示スコア範囲・譜面定数・ジャンル・バージョンは表示時に適用します。

難易度別の平均スコアは静的配信元の `/v1/chart-scores/{DIFFICULTY}.json` から取得します。`PUBLIC_CHART_SCORES_BASE_URL` が設定されている場合はその配信元を使用し、未設定時はフロントエンドのホスト名へ `static.` を付けます。ローカル開発では `https://static.chunisup-dev.f5.si` を指定します。

静的統計の平均はクリア済み記録から算出されます。比較対象は自分のプレイ済み記録で、選択レート帯の平均が `null` の譜面と未プレイ譜面は表示しません。

## 表示

差分は `自分のスコア − 平均スコアの整数部分` です。散布図では横軸に表示対象の最低定数から最高定数まで、縦軸に差分を表示します。縦軸の0点を中央に置き、上下とも設定した表示スコア範囲を描画します。表示範囲外の点はグラフと表から除外します。平均より低い譜面と平均以上の譜面を色分けし、通常版と同じジャケット背景付きツールチップと表で詳細を確認できます。表は仮想スクロールで全件を表示し、各ヘッダーから並び順を変更できます。
