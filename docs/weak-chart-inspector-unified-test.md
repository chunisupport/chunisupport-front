# 苦手譜面インスペクター Unified_test

`/tools/weak-chart-inspector-unified-test` は管理者向けの試作分析ページです。ツール一覧の「分析・比較」には `ADMIN` にだけ表示し、直接URLを開く場合も `ADMIN` 権限とプレイヤーデータ登録を要求します。通常の苦手譜面インスペクターの新版（Unified）は従来の計算を維持します。

## 計算方式

既存の Unified は失点を最低100点として扱うため、100落ちから理論値までの差が評価に反映されません。また、比較平均が理論値に近い譜面では、理論値でも普段の失点比に届かず「苦手」になる場合があります。試作版では両方に対応します。

```text
自分の失点 = 1,010,000 − 自分のスコア
平均の失点 = 1,010,000 − 平均スコア
失点比 = ln((平均の失点 + 100) / (自分の失点 + 100))
到達可能上限 = ln((平均の失点 + 100) / 100)
比較基準 = min(近い定数帯での失点比の中央値, 到達可能上限)
ずれ = (失点比 − 比較基準) / ばらつき
```

失点に加える補正値は試作時点で100点です。100落ち・50落ち・10落ち・理論値の計算値は、それぞれ200・150・110・100となり、連続的に区別します。中央値とばらつきも、この加算方式による失点比から求めます。既存の下限方式による基準は流用しません。

比較基準を、その譜面で理論値を取った場合の失点比以下に抑えます。そのため、比較平均がある理論値譜面のずれは必ず0以上となり、「苦手」「やや苦手」になりません。従来の基準を上回っていれば「得意」にもなります。

## 共通仕様と試作上の制限

比較範囲（前後0.5、5譜面未満は全譜面）、中央値・MADによるばらつき、ばらつきの下限0.1、得意度への換算・整数丸め・20〜80の制限、判定閾値は[通常の新版](./weak-chart-inspector.md)と共通です。データ取得、初期設定、表示・集計範囲、散布図、一覧、ソートも共通画面を利用します。

得意度は丸めと上下限を持つため、計算上のずれが改善しても表示上の整数が同じになる場合があります。また、試作版も中央値・ばらつきへの上限到達譜面の影響自体は補正しません。補正値100点とばらつき下限の組み合わせによる、理論値付近の判定の敏感さは今後の比較対象です。
