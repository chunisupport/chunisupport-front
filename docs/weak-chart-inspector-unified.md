# 苦手譜面インスペクター Unified

`/tools/weak-chart-inspector-unified` は管理者向けの苦手譜面分析ページです。ツール一覧では管理者にだけ表示され、直接URLを開く場合も `ADMIN` 権限が必要です。プレイ記録から求めた自分のスコア分布での外れ値と、選択したレート帯の譜面別平均スコアをまとめて確認できます。

## データと初期設定

分析対象はプレイ済みの通常譜面で、スコアが理論値の1,010,000点以下の記録です。選択した難易度の対象記録から、譜面定数を小数第1位に切り捨てたグループごとに個人のTukey外れ値を求めます。レート帯平均がない記録もこの計算に含めます。下側フェンスは `Q1 − 2 × IQR`、上側フェンスは `Q3 + 0.6 × IQR` です。

レート帯の譜面別平均は、楽曲IDと難易度の組み合わせで照合します。平均データが存在しない譜面、または選択レート帯の `average_score` が `null` の譜面は「データなし」と判定されます。平均の小数部分を切り捨て、自分のスコアから引いて差分を求めます。

難易度の初期選択は `MASTER` と `ULTIMA`、弱点判定の点差閾値は1,000点です。レート帯はログインユーザーの `best_average` に該当する帯を初期選択し、該当帯がない場合は最高帯を選択します。点差閾値は0～1,010,000点の整数で設定でき、入力を空欄にしている間は初期値の1,000点として判定します。レート帯、点差閾値、難易度は画面上で変更できます。判定はアイコン付きの切り替えボタンで絞り込み、各ボタンに件数を表示します。点差閾値の入力欄は「− 1000 点」のように、平均を下回る点数として表示します。

## 判定

判定は次の順に決めます。外れ値は自分のスコア分布での外れ値です。

| 画面上の判定 | 条件 |
| --- | --- |
| データなし | 選択レート帯の譜面別平均がない |
| 苦手 | LOW外れ値で、差分が負かつ `差分 <= -閾値` |
| 苦手かも | LOW外れ値で、「苦手」の条件に当てはまらない |
| 平均未満 | LOW外れ値ではなく、差分が負かつ `差分 <= -閾値` |
| 得意 | LOW外れ値ではなく、平均未満にも当てはまらず、HIGH外れ値または差分が正 |
| 平均並み | 上記のいずれにも当てはまらない |

点差閾値は、平均をどれだけ下回った譜面を弱点候補にするかを決めます。閾値が0の場合も、平均未満の判定には差分が負であることが必要です。差分0の譜面は、外れ値による判定がなければ「平均並み」です。

## 表示

結果は「苦手」「平均未満」「苦手かも」「平均並み」「得意」「データなし」の順に並びます。同じ判定の中では差分を小さい順にし、差分のない譜面を最後に置きます。差分が同じ場合は楽曲の読み順で並びます。

一覧には曲名、難易度、譜面定数、スコア、平均、点差、外れ値、判定を表示します。曲名は左寄せ、その他の列は中央揃えです。難易度はレコードと同じ1文字のバッジで示します。外れ値は低外れ値を下向き矢印、高外れ値を上向き矢印、通常を横線のアイコンで示します。判定はアイコン付きの色バッジで示します。
