# 苦手譜面インスペクター Unified

`/tools/weak-chart-inspector-unified` は管理者向けの苦手譜面分析ページです。ツール一覧では管理者にだけ表示され、直接URLを開く場合も `ADMIN` 権限が必要です。選択したレート帯の譜面別平均スコアとの失点比を、自分の普段の失点比と比べて、相対的に伸びていない譜面を確認できます。

## データと初期設定

分析対象はプレイ済みの通常譜面で、スコアが理論値の1,010,000点以下の記録です。

レート帯の譜面別平均は、楽曲IDと難易度の組み合わせで照合します。平均データが存在しない譜面、または選択レート帯の `average_score` が `null` の譜面は「データなし」と判定されます。理論値からの失点（`1,010,000 − スコア`）を自分と平均でそれぞれ求め、`失点比 = ln(平均の失点 / 自分の失点)` とします。平均より失点が少ないほど大きく、平均と同じ失点なら0です。失点は100点を下限とし、理論値付近で数十点の差が大きな比にならないようにします。

失点はおおよそミスの数に比例するため、点差ではなく失点の比を使うことで、高得点帯ほどスコアが上がりにくいことと、ノーツ数による1ミスあたりの失点の違いを打ち消します。たとえば平均1,008,000点に対する1,009,000点（失点を半分にした）は、平均995,000点に対する996,000点（失点を約7%減らした）より高く評価されます。

難易度の初期選択は `MASTER` と `ULTIMA` です。レート帯はログインユーザーの `best_average` に該当する帯を初期選択し、該当帯がない場合は最高帯を選択します。レート帯と難易度は画面上で変更できます。判定はアイコン付きの切り替えボタンで絞り込み、各ボタンに件数を表示します。ユーザーが入力する閾値はありません。

## 判定

失点比そのものではなく、自分の普段の失点比からのずれで判定します。これにより、選択レート帯と自分の地力の差や、譜面定数帯ごとのスコアの伸びにくさを打ち消します。

1. 譜面定数を小数第1位に切り捨て、前後0.5以内（例: 14.0なら13.5～14.5）の比較できる譜面を、判定する譜面自身も含めて集めます。5譜面未満の場合は、比較できる全譜面を使います。
2. 集めた譜面の失点比の中央値を「普段の失点比」とします。
3. 失点比の中央絶対偏差（MAD）に1.4826を掛けた値をばらつきとし、`ずれ = (失点比 − 普段の失点比) / ばらつき` を求めます。ばらつきの下限は0.1（失点で約1割の違い）とし、失点比がほぼ揃った定数帯でわずかなずれを過敏に判定しないようにします。
4. ずれを偏差値形式の得意度 `50 + 10 × ずれ` に換算し、整数に丸めて20～80の範囲に収めます。50が普段どおりです。

判定は、表示する得意度と食い違わないよう、丸めた後の得意度で決めます。

| 画面上の判定 | 条件 |
| --- | --- |
| データなし | 選択レート帯の譜面別平均がない |
| 苦手 | `得意度 <= 30` |
| やや苦手 | `30 < 得意度 <= 40` |
| 得意 | `得意度 >= 60` |
| ふつう | 上記のいずれにも当てはまらない |

平均を上回る譜面でも、普段の失点比より大きく劣れば「苦手」になります。逆に、全体的に平均を下回っていても、普段どおりの譜面は「ふつう」です。

## 表示

結果は「苦手」「やや苦手」「ふつう」「得意」「データなし」の順に並びます。同じ判定の中ではずれを小さい順にし、ずれが同じ場合は楽曲の読み順で並びます。

一覧には曲名、難易度、譜面定数、スコア、得意度、判定を表示します。レート帯平均、失点比、普段の失点比は判定の材料としてだけ使い、表示しません。曲名は左寄せ、その他の列は中央揃えです。難易度はレコードと同じ1文字のバッジで示します。得意度は数値と、50を中心に左右へ伸びる判定色のバーで示します。データなしの譜面は「—」を表示します。判定はアイコン付きの色バッジで示します。

すべての列ヘッダーはクリックで昇順、降順、初期順（上記の判定の優先順位）を切り替えられます。難易度は `BASIC` から `ULTIMA` の順、判定は上記の優先順位の順で比べます。得意度で並べる場合、得意度がない譜面はソート方向にかかわらず末尾に置きます。値が同じ場合は初期順を保ちます。
