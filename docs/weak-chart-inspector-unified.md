# 苦手譜面インスペクター Unified

`/tools/weak-chart-inspector-unified` は管理者向けの苦手譜面分析ページです。ツール一覧では管理者にだけ表示され、直接URLを開く場合も `ADMIN` 権限が必要です。選択したレート帯の譜面別平均スコアとの点差を、自分の普段の点差と比べて、相対的に伸びていない譜面を確認できます。

## データと初期設定

分析対象はプレイ済みの通常譜面で、スコアが理論値の1,010,000点以下の記録です。

レート帯の譜面別平均は、楽曲IDと難易度の組み合わせで照合します。平均データが存在しない譜面、または選択レート帯の `average_score` が `null` の譜面は「データなし」と判定されます。平均の小数部分を切り捨て、自分のスコアから引いて点差を求めます。

難易度の初期選択は `MASTER` と `ULTIMA` です。レート帯はログインユーザーの `best_average` に該当する帯を初期選択し、該当帯がない場合は最高帯を選択します。レート帯と難易度は画面上で変更できます。判定はアイコン付きの切り替えボタンで絞り込み、各ボタンに件数を表示します。ユーザーが入力する閾値はありません。

## 判定

点差そのものではなく、自分の普段の点差からのずれで判定します。これにより、選択レート帯と自分の地力の差や、譜面定数帯ごとのスコアの伸びにくさを打ち消します。

1. 譜面定数を小数第1位に切り捨て、前後0.5以内（例: 14.0なら13.5～14.5）の比較できる譜面を、判定する譜面自身も含めて集めます。5譜面未満の場合は、比較できる全譜面を使います。
2. 集めた譜面の点差の中央値を「普段の差」とします。
3. 点差の中央絶対偏差（MAD）に1.4826を掛けた値をばらつきとし、`ずれ = (点差 − 普段の差) / ばらつき` を求めます。ばらつきの下限は100点とし、点差がほぼ揃った定数帯で数十点のずれを過敏に判定しないようにします。

| 画面上の判定 | 条件 |
| --- | --- |
| データなし | 選択レート帯の譜面別平均がない |
| 苦手 | `ずれ <= -2` |
| やや苦手 | `-2 < ずれ <= -1` |
| 得意 | `ずれ >= 1` |
| ふつう | 上記のいずれにも当てはまらない |

平均を上回る譜面でも、普段の差より大きく低ければ「苦手」になります。逆に、全体的に平均を下回っていても、普段どおりの譜面は「ふつう」です。

## 表示

結果は「苦手」「やや苦手」「ふつう」「得意」「データなし」の順に並びます。同じ判定の中ではずれを小さい順にし、ずれが同じ場合は楽曲の読み順で並びます。

一覧には曲名、難易度、譜面定数、スコア、平均、点差、普段の差、判定を表示します。曲名は左寄せ、その他の列は中央揃えです。難易度はレコードと同じ1文字のバッジで示します。普段の差は整数に丸めて表示します。判定はアイコン付きの色バッジで示します。

すべての列ヘッダーはクリックで昇順、降順、初期順（上記の判定の優先順位）を切り替えられます。難易度は `BASIC` から `ULTIMA` の順、判定は上記の優先順位の順で比べます。平均・点差・普段の差で並べる場合、平均がない譜面はソート方向にかかわらず末尾に置きます。値が同じ場合は初期順を保ちます。
