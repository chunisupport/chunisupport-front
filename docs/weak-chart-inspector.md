# 苦手譜面インスペクター

`/tools/weak-chart-inspector` は苦手譜面の分析ページです。見出し横の切り替えで「新」と「旧」を選べます。初期表示は新版で、選択した版は localStorage に保存し、次回以降も使います。読み込みに失敗した版からも切り替えられるよう、見出しと切り替えは常に表示します。版を切り替えると、切り替え先の版はデータを取得し直し、レート帯や絞り込みなどの設定は初期値から始まります。

## 新版

選択したレート帯の譜面別平均スコアとの失点比を、自分の普段の失点比と比べて、相対的に伸びていない譜面を確認できます。

### データと初期設定

分析対象はプレイ済みの通常譜面で、スコアが理論値の1,010,000点以下の記録です。

レート帯の譜面別平均は、楽曲IDと難易度の組み合わせで照合します。平均データが存在しない譜面、または選択レート帯の `average_score` が `null` の譜面は「データなし」と判定されます。理論値からの失点（`1,010,000 − スコア`）を自分と平均でそれぞれ求め、`失点比 = ln((平均の失点 + 100) / (自分の失点 + 100))` とします。平均より失点が少ないほど大きく、平均と同じ失点なら0です。自分と平均の失点に100点を加えることで、理論値でのゼロ除算を防ぎながら、100落ち・50落ち・20落ち・理論値のような高得点帯の差も区別します。

点差ではなく補正後の失点の比を使い、高得点帯ほどスコアが上がりにくいことを考慮します。たとえば平均1,008,000点に対する1,009,000点は、平均995,000点に対する996,000点より失点比が大きくなります。同じ1,000点の上積みでも、理論値に近づけた成果をより大きく評価します。

レート帯はログインユーザーの `best_average` に該当する帯を初期選択し、該当帯がない場合は最高帯を選択します。判定はアイコン付きの切り替えボタンで絞り込み、各ボタンに件数を表示します。ユーザーが入力する閾値はありません。

### 表示・集計範囲

レート帯の右の設定から、Online と共通の表示・集計範囲ダイアログ（`src/components/common/WeakChartSettingsDialog.tsx`）で、難易度、ジャンル、バージョン、楽曲名順、レベル／譜面定数範囲を変更できます。Online にある表示スコア範囲は、縦軸が得意度で固定のため使用しません。初期値は難易度が `MASTER` と `ULTIMA`、その他は全範囲です。範囲はレベル指定を既定とし、「譜面定数で指定」で数値入力へ切り替えます。適用した範囲と入力モードはダイアログを開き直しても維持し、キャンセルした変更は破棄します。「初期値に戻す」は編集中の範囲とモードを初期化し、「適用」で確定します。範囲条件と入力モードはストレージに保存しません。逆順の範囲は適用時に昇順に揃え、レベル指定では各レベル全体を含めます。

難易度は判定の集計範囲です。選択した難易度の譜面だけで普段の失点比を求め、判定します。難易度には通常譜面に加えて `OP対象（MAS+ULT）` があり、通常難易度と同時に選択できません。`OP対象（MAS+ULT）` は楽曲マスタの理論値OVER POWER対象譜面だけを集計し、平均スコアは `MASTER` と `ULTIMA` から取得します。

譜面定数・ジャンル・バージョン・楽曲名順は、判定の後に表示だけを絞り込みます。判定前に絞り込むと普段の失点比が変わり、同じ譜面の得意度が絞り込みによって変わるためです。判定の切り替えボタンの件数、散布図、一覧は絞り込み後の譜面を対象にします。統計の再取得と判定の再計算は、難易度を変更した場合だけ行います。

### 判定

失点比そのものではなく、自分の普段の失点比からのずれで判定します。これにより、選択レート帯と自分の地力の差や、譜面定数帯ごとのスコアの伸びにくさを打ち消します。

1. 譜面定数を小数第1位に切り捨て、前後0.5以内（例: 14.0なら13.5～14.5）の比較できる譜面を、判定する譜面自身も含めて集めます。5譜面未満の場合は、比較できる全譜面を使います。
2. 集めた譜面の失点比の中央値を「普段の失点比」とします。
3. 判定する譜面で理論値を取った場合の失点比 `到達可能上限 = ln((平均の失点 + 100) / 100)` を求め、`比較基準 = min(普段の失点比, 到達可能上限)` とします。譜面ごとに達成できる上限を超えた成績を要求しないための補正です。
4. 失点比の中央絶対偏差（MAD）に1.4826を掛けた値をばらつきとし、`ずれ = (失点比 − 比較基準) / ばらつき` を求めます。ばらつきの下限は0.1とし、失点比がほぼ揃った定数帯でわずかなずれを過敏に判定しないようにします。中央値とばらつきはいずれも、失点に100点を加えた方式で算出します。
5. ずれを偏差値形式の得意度 `50 + 10 × ずれ` に換算し、整数に丸めて20～80の範囲に収めます。50が比較基準どおりです。

判定は、表示する得意度と食い違わないよう、丸めた後の得意度で決めます。

| 画面上の判定 | 条件 |
| --- | --- |
| データなし | 選択レート帯の譜面別平均がない |
| 苦手 | `得意度 <= 30` |
| やや苦手 | `30 < 得意度 <= 40` |
| 得意 | `得意度 >= 60` |
| ふつう | 上記のいずれにも当てはまらない |

平均を上回る譜面でも、普段の失点比より大きく劣れば「苦手」になります。逆に、全体的に平均を下回っていても、普段どおりの譜面は「ふつう」です。

比較平均がある理論値譜面のずれは必ず0以上となり、得意度は50以上になります。理論値を一律に「得意」にするわけではなく、比較基準からの上積みに応じて評価します。理論値直前のスコアも連続的に区別しますが、得意度は整数丸めと20～80の制限を持つため、スコアが伸びても表示値が変わらない場合があります。

### 表示

判定の切り替えボタンの下に、横軸が譜面定数、縦軸が得意度の散布図を表示し、その下に一覧を表示します。

散布図の点は判定の色で塗ります。縦軸は得意度の下限20から上限80までを10刻みで目盛り、普段どおりの50の線を強調します。背景は「苦手」「やや苦手」「得意」の得意度範囲を判定の色で塗ります。得意度は整数のため、背景の境界は判定の閾値から0.5ずらし（30.5、40.5、59.5）、各判定の点が必ず対応する背景の内側に描かれるようにします。同じ定数・得意度の点が重ならないよう、横方向へ7段階にずらします。点にカーソルを合わせると、ジャケットを背景にした曲名、難易度、譜面定数、スコア、得意度、判定を表示します。データなしの譜面は得意度がないため描きません。

判定の切り替えは散布図にも適用します。点の位置と横軸の範囲は、表示・集計範囲で絞り込み、判定では絞り込む前の譜面から求めるため、判定を切り替えても変わりません。譜面定数を絞り込むと、横軸も絞り込んだ範囲に合わせて狭まります。表示中の判定に得意度がある譜面がない場合も、軸・背景・基準線を含む空の散布図を表示します。全譜面がデータなしの場合の横軸は表示対象の譜面定数から求め、表示対象の譜面自体がない場合は表示・集計範囲で指定した譜面定数の範囲を使います。狭い画面では、散布図は最小幅を保ったまま横スクロールします。

結果は「苦手」「やや苦手」「ふつう」「得意」「データなし」の順に並びます。同じ判定の中ではずれを小さい順にし、ずれが同じ場合は楽曲の読み順で並びます。

一覧には曲名、難易度、譜面定数、スコア、得意度、判定を表示します。レート帯平均、失点比、普段の失点比は判定の材料としてだけ使い、表示しません。曲名は左寄せ、その他の列は中央揃えです。難易度はレコードと同じ1文字のバッジで示します。得意度は数値と、50を中心に左右へ伸びる判定色のバーで示します。データなしの譜面は「—」を表示します。判定はアイコン付きの色バッジで示します。

すべての列ヘッダーはクリックで昇順、降順、初期順（上記の判定の優先順位）を切り替えられます。難易度は `BASIC` から `ULTIMA` の順、判定は上記の優先順位の順で比べます。得意度で並べる場合、得意度がない譜面はソート方向にかかわらず末尾に置きます。値が同じ場合は初期順を保ちます。

## 旧版

自分のスコア分布だけで分析します。プレイ済み通常譜面を譜面定数ごとの散布図で示し、外れ値を「得意かもしれない譜面」「苦手かもしれない譜面」の表に表示します。難易度・スコア・レベル／譜面定数の集計範囲と、グラフの表示範囲を設定から変更できます。集計対象と表示範囲はそれぞれ独立して、レベル指定と「譜面定数で指定」を切り替えられます。適用・キャンセル・初期値へのリセットと、範囲・入力モードの保持は新版と同じ扱いです。
